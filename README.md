# CMYORA

### Luxury Leather Handbags

Official website development repository for CMYORA.

Website: https://cmyora.com

---

## About

CMYORA is a leather handbag brand focused on
design, craftsmanship, and contemporary fashion.

This repository contains the source code,
design assets, and documentation for the
official CMYORA website.

---

## Project Status

 Under Development

The initial release will provide a Coming Soon
landing page introducing the CMYORA brand.

Future releases are planned to include:

- Responsive brand website
- Product collections
- Product detail pages
- Image galleries
- Contact and enquiry functionality
- Advanced product browsing
- Potential e-commerce integration

## Local Development

Clone the repository:

    git clone https://github.com/Raunak-Singh-Negi/cmyora.git

Navigate into the project:

    cd cmyora

Install dependencies:

    npm install

Start the development server:

    npm run dev

---
